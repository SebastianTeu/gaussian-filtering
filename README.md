# Pre-Render Filtering of Unstable Gaussians for Improved Extreme View Synthesis in 3D Gaussian Splatting

Project page for Sebastian Teuttli's honors thesis (Barrett, The Honors College at Arizona State University, 2026).
The thesis introduces an offline, pre-render filter, inspired by EV3DGS, that prunes unstable Gaussians so 3D Gaussian Splatting scenes render more cleanly from out-of-distribution camera poses, without affecting real-time rendering.

**Live page:** https://sebastianteu.github.io/gaussian-filtering

**Code:** https://github.com/SebastianTeu/gsplat-ood-filter
